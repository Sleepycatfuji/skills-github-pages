CHECK THE ORIGINAL CONTEXT

DOCUMENTS → ACTIONS → TICKETS

Start with the material you have.

  1. Upload PDFs, DOCX, TXT or Markdown files, or add pasted notes and summaries.
  2. Preview the extracted text, add project context, and choose a small-change point reference.
  3. Generate a batch. Local rules work without an API key. Optional AI drafting handles more unstructured material and incurs API usage.
  4. Edit titles, criteria and estimates. Check source quotes, select tickets, then export a Jira CSV or JSON.

PDFs must contain selectable text; scanned PDFs require OCR first. DOCX reads main document paragraphs and tables, not images, comments, tracked-change history, headers or footers. File limits are 10 MB each, 100 pages per PDF, 8 sources, and 120,000 extracted characters per batch.

Local mode is a heuristic, not a live AI model. It can miss work or group it incorrectly. Story points are discussion starters, not hours or calibrated team estimates. File contents and drafts remain in browser memory. AI mode sends extracted text to your server and OpenAI only when you request generation; raw files are not sent. The app never connects to Gmail or automatically creates Jira issues.
